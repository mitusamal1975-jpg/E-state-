# EstateAI Prototype

Follow these 4 simple steps to run the EstateAI application locally:

**Step 1: Install Dependencies**
Open your terminal/command prompt in the folder containing these files and run:
`pip install -r requirements.txt`

**Step 2: Start the Backend Server**
In the same terminal, start the Flask server by running:
`python app.py`

**Step 3: Wait for Server Confirmation**
Make sure the terminal shows the server is running on `http://127.0.0.1:5000` (Leave this terminal window open).

**Step 4: Launch the Frontend**
Double-click the `index.html` file in your file explorer to open it in your web browser. The app will automatically connect to the backend and display the properties!
